# Python Starter

A small Python project that demonstrates a maintainable `src` layout.

## Set up

```powershell
cd "D:\Yuva\Game Developer\python-starter"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

## Run

```powershell
python -m python_starter
```

## Test

```powershell
pytest
```
